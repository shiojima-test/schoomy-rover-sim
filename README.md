# schoomy-rover-sim

月面自律探査シミュレーター — スクーミー宇宙プロジェクト MISSION 02

**公開URL** https://shiojima-test.github.io/schoomy-rover-sim/

RUN_028（2026年8月15日の実機検証）で記録した実測データを再生し、
ローバーが段差を越えるときの車体の傾きと、そこから床からのタイル枚数を
読み取る過程を可視化します。

## 実測と推定の区別

| | 内容 |
| --- | --- |
| **実測データ** | 車体の傾き（angX）、向きのずれ（angZ）、加速度の大きさ、時刻 |
| **推定** | 走行位置。境界の通過時刻は実測、その間は等速で補間している |

センサーは加速度・角度のみで、位置を測る手段は載せていません。

## 元データ

- 走行ログ RUN_028（9,361点 / 40.0秒 / 平均234Hz）
- 表示用に1,873点へ間引き。区間内で |angX| が最大の点を代表にしているためピークは保たれる
- 実測の全データと解析スクリプトは `shiojima-test/schoomy-space-project`（private）

## フィールド

ダイソーのジョイントマット 30cm角・厚さ1cm を6枚一列。
床からの積み枚数は **2・1・3・1・2・1**。

角度の符号は **負＝上り／正＝下り**（ファームウェアが `rel = 基準 − 現在値` で計算しているため）。

## 見せ方

表示は2通りあります。「タイルを見せる」ボタンで切り替えます。

**伏せるモード（既定）**
走行中は**平らな床の上をローバーが走るだけ**で、タイルもフィールドの枠も出しません。
傾いたり跳ねたりしますが、何の上を走っているかは見えない状態です。
分かるのは、グラフの波形と、境界を越えるたびに埋まっていく判定パネルだけ。

走り終わると、**セル1から順にタイルがせり上がって**フィールドが現れ、
最後に答え合わせの帯が出ます。
「センサーのデータだけで地形を読み取った」という流れをそのまま見せられます。

**見せるモード**
最初から6セルすべてのタイルと判定を表示します。
配置と波形の対応を説明したいときはこちら。

グラフの波形は、どちらのモードでも全区間を薄いグレーで描いてあり、
走った分だけ色がつきます。

## 操作

| | |
| --- | --- |
| 再生 / 一時停止 | ボタン または スペースキー |
| 速度 | 0.5倍 / 1倍 / 2倍 |
| 視点 | ななめ後方 / 真横 / 全体 / 前方から |
| 画面操作 | ドラッグで回転、ホイールで拡大縮小 |
| 録画モード | 操作パネルを薄くして最初から自動再生 |
| コマ送り | ← → キー（1コマ20ミリ秒） |
| 時刻ジャンプ | グラフをクリック／判定カードをクリック |
